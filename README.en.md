## 🍄 Mushroom Mouse Helper · 蘑菇鼠标助手

![A tiny mushroom hugging a computer mouse](assets/shroom-mouse-banner.png)

A **vibe-coded** helper for **Shroom and Gloom**.

Two floating mouse buttons add **forward / backward movement**, making mouse-only dungeon wandering a little easier. Click, wiggle, off we go!

It only adds W / S controls. Screens that need other keyboard keys still need those keys.

**Windows · Free · Experimental**

**[Windows ZIP (.3)](https://github.com/miaomiao-tools/miaomiao-tools/releases/download/mm-001-v0.1.0-experimental.3/ShroomMouse-0.1.0-experimental.3-win-x64.zip)** · **[Release page](https://github.com/miaomiao-tools/miaomiao-tools/releases/tag/mm-001-v0.1.0-experimental.3)** · **[Report an issue](https://github.com/miaomiao-tools/miaomiao-tools/issues)** · **[How to use it](自建_蘑菇鼠标助手/README.en.md)**

**0.1.0-experimental.3 · Experimental** fixes the panel being covered by the game, adds game reselection, and keeps the download tidy. The app interface is currently Chinese.

In the current real game, panel display was confirmed; the user confirmed forward/backward movement and stopping on release or moving off the button. Other environments and long holds remain unverified.

When upgrading, exit the old helper normally before extracting the new version. Follow the guide to keep personal settings; do not share those files.

Extract the download, open the helper, and select your game executable on first launch. The current app interface is in Chinese; the English guide explains its buttons and limitations.
