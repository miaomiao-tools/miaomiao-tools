## 🍄 蘑菇鼠标助手

![小蘑菇抱着鼠标](assets/shroom-mouse-banner.png)

一个用 **vibe coding** 做出来的《Shroom and Gloom》小助手。

给前进、后退补上鼠标按钮，让全鼠标逛蘑菇地牢更顺手。点一点，出发啦～

**Windows · 免费 · 实验版**
