# 使用说明

[English](USAGE.en.md) · [返回首页](../README.md)

## 日常检测

首次启动展示等待检测的空状态，不会自动探测服务。点击「轻量检测」或按 **F5** 检查一次。默认「路由器 / 网关」模式由 Windows 正常路由连接，适合路由器代理；不会修改系统代理、路由或网关设置。

完整面板可选择「系统 / 环境代理」，或填写不带账号密码的 HTTP / SOCKS5 代理。连接方式应与实际使用的 agent 相符；不同软件可以使用不同线路，检测结果不代表所有软件走了同一路径。自定义服务仅接受 HTTP / HTTPS 地址，不接受凭据、查询参数或片段。

轻量检测通过 DNS、TCP 与 HTTPS 的 TLS 握手观察连接，始终验证证书。目标为 HTTP 地址时没有 TLS 阶段。代理模式中，相关阶段可能反映到代理的连接；详情会标出实际连接主机与检测范围。HTTP 代理的 CONNECT 协商仍会与代理通信。

需要目标服务响应时，在完整面板选择一个服务，点击手动 HTTP 检查。每次只检查所选项，不跟随重定向，不带 Cookie 或认证信息，也不产生模型生成调用。

## 副屏迷你模式

- **Ctrl+M** 切换完整 / 迷你面板。也可使用「迷你模式」和展开按钮。
- 拖动顶部移动窗口，拖动边缘调整大小；列表可滚动。
- **Ctrl+T** 或图钉切换置顶；窗口会记住位置、大小、模式和置顶状态。
- 单击服务查看说明，悬停查看完整提示，双击服务返回完整面板。
- 自动巡检最短 **5 分钟**一次，每次重启默认关闭。两个面板共用同一任务和计时器，切换不触发检测。
- 关闭窗口会退出程序并停止巡检。启动参数 `--mini` / `--full` 可指定模式，直接启动恢复上次模式。

## 结果与保护

| 提示 | 如何理解 |
| --- | --- |
| 连接成功 | 本轮检测涉及的传输阶段可达；不代表登录或模型生成成功 |
| 需要认证 / 401 | 服务返回了 HTTP 响应，但本工具不验证账号 |
| 403 / 校验 / 451 | 可能涉及人机验证、权限或访问限制；不能仅凭它确认 IP 被封 |
| 429 | 服务正在限流，等保护期结束再试 |
| 404 / 重定向 | 已收到响应，具体服务能力仍待确认 |
| 超时 / 连接或证书错误 | 查看失败阶段、所选网络方式和详情；不会跳过证书验证 |
| 保护期 | 本次跳过该域名，没有连接目标 |

同一域名的轻量检测至少间隔 **60 秒**，手动 HTTP 至少 **10 分钟**。连接失败逐步退避；403、429、451 和已识别人机校验会暂停该域名，重复受限可延长到 24 小时，服务方给出的更长 `Retry-After` 会继续遵守。冷却先保存再联网，重启、切换线路、切换面板和清空历史不会重置它；无法可靠保存冷却时暂停检测。

这些机制减少探测负担，无法保证零风控。无痕模式主要隔离浏览器会话，不会替换出口 IP，也不能保证绕过限制；[Chrome 官方说明](https://support.google.com/chrome/answer/95464?hl=zh-Hans)也明确，网站与网络提供方仍可能观察活动。本工具不读取浏览器会话；日常优先用低频轻量检测。

## 数据、升级与恢复

把程序完整解压到可写目录。数据通常在 EXE 旁的 `data`：`settings.json`、`history.json`、`cooldowns.json`、`window.json`。导出报告可能包含自定义地址和连接 IP，分享前先检查。

升级时正常退出旧版，备份并复制**整个 `data` 文件夹**到新程序旁。新目录不会自动继承旧数据或保护期。若曾出现目录不可写提示，请从提示中的实际数据目录迁移。回退时退出新版，使用保留的旧程序和升级前完整数据备份，不要只换回某一个配置文件。

发现另一个实例时，新实例不会开始探测。公开版遇到旧版运行会提示先使用或正常退出现有程序，不会强制关闭它。数据保存或保护记录异常时，保留原文件，检查权限与磁盘空间，不要删除冷却文件来解除暂停。
