# 🍄 蘑菇鼠标助手 / Mushroom Mouse Helper 0.1.0-experimental.1

## 中文

小蘑菇，用鼠标出发啦！

这是 **vibe coding** 做出来的实验小工具，为《Shroom and Gloom》的全鼠标游玩补上 **前进 / 后退** 悬浮按钮。点击短移，按住持续；松开、移出按钮或切换软件就停下。

**下载** `ShroomMouse-0.1.0-experimental.1-win-x64.zip` → 完整解压 → 打开助手 → 首次选中游戏的 `Shroom and Gloom.exe` → 回到游戏试试。用完点 **×** 即可退出。

- Windows 10 / 11 64 位，需要 .NET Framework 4.8 / 4.8.1；推荐游戏窗口化或无边框。
- 只补 W / S，其他操作沿用游戏原有方式；不保证每个画面都能完全摆脱键盘。
- 实验版：已做离线检查，本发布候选尚未重测实际游戏、全屏和多屏操作。
- 独立小工具，不改游戏文件和存档，不包含游戏或中文补丁，与游戏官方无关联。

自有代码使用 MIT 许可，欢迎翻翻源码。下载校验值见随附 `SHA256SUMS.txt`。🌱

## English

A little mushroom, ready to wander with your mouse!

This **vibe-coded** experiment adds floating **forward / backward** buttons for mouse-only play in **Shroom and Gloom**. Click for a short move, or hold to keep moving. Releasing, moving off the button, or switching apps releases the key.

**Download** `ShroomMouse-0.1.0-experimental.1-win-x64.zip` → extract everything → open `蘑菇鼠标助手.exe` → select your installed `Shroom and Gloom.exe` on first launch → return to the game. Click **×** to exit.

- Windows 10 / 11, 64-bit; requires .NET Framework 4.8 / 4.8.1. Windowed or borderless mode is recommended.
- Only W / S are added. Other controls stay with the game; some screens still need a keyboard.
- Experimental: offline checks passed; actual gameplay, fullscreen, and multiple monitors have not been retested for this candidate.
- Independent and unofficial. No game-file or save changes, and no bundled game or translation patch.
- The app interface is currently in Chinese. The [English guide](https://github.com/miaomiao-tools/miaomiao-tools/blob/main/自建_蘑菇鼠标助手/README.en.md) explains its button labels and use.

The project's own code is MIT-licensed. Download checksums are listed in `SHA256SUMS.txt`. Little tools, growing slowly 🌱
