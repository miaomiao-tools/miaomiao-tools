## 0.1.0-experimental.2 · 本地候选，尚未发布

- 设置和托盘增加「重新选择游戏…」；先释放按键并暂停输入，保存成功才切换，取消或失败保留原目标和配置。
- 路径配置改为原子保存，切换时清理旧目标缓存，继续按完整路径匹配。
- 修复英文说明漏打包和构建目录旧文档问题；两种 ZIP 都包含中英说明、蘑菇插图与真实助手测试窗口截图。
- 构建和打包支持独立目录、中文和空格路径，校验构建来源、白名单、相对链接及图片。
- 四个首页补充明确的 .1 Windows ZIP 下载与 Issue 反馈入口，区分本地 .2 与公开 .1；程序界面仍为中文。
- 本轮不发布，不覆盖旧标签或附件。离线回归和助手测试窗口操作不等同于游戏内实测。

## 0.1.0-experimental.1

首个独立实验发布候选，以个人使用版为基础：

- 移除固定本机游戏路径，首次选择安装文件，继续按完整路径识别前台游戏。
- 从当前 Windows 环境定位构建工具，补充公开版本元数据、适用环境、隐私及第三方声明。
- 打包使用明确文件清单，不附带个人配置、历史日志、调试符号或游戏补丁。
- 保留 W/S 输入逻辑、短点击、松开释放、焦点保护、30 秒保护及单实例限制。

该版本号是公开实验系列的独立编号，不表示历史个人版的 v1.0 已完成同范围公开验证。
