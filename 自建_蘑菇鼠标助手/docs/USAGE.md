# 使用细节与边界

**中文** · [English](USAGE.en.md)

## 设置和恢复

- 布局存于 EXE 旁边的 `controls.ini`；选定的游戏绝对路径存于 `game-path.txt`。目录不可写时可本次使用，但设置可能无法保留。
- 重新选择游戏：在「设置」或通知区右键菜单中点 **重新选择游戏…**。选择前释放助手按住的 W/S、暂停输入；取消、无效文件或保存失败保留原目标与配置。保存成功才切换到新路径，需重新按下按钮才会移动。游戏文件不存在或首次保存路径失效时也会重新选择。
- 若按键未成功释放，助手不打开选择框，保留所有权并继续重试释放。测试模式固定连接测试窗口，不能通过该入口改成游戏。
- 恢复布局：退出后删除 `controls.ini`，或使用通知区的“重置位置和大小”。
- 如果另一个版本正在运行，请自行正常退出后再体验；助手保留单实例限制，不会关闭已有程序。
- 卸载：正常退出后删除解压文件夹即可，无须恢复游戏。没有服务、驱动、注册表修改或开机启动项。
- 分享自己的助手文件夹前移除 `controls.ini` 和 `game-path.txt`，这些文件属于个人设置。手动开发验证生成的日志也不要一起分享。

## 输入行为

助手运行时安装 Windows 鼠标钩子，拦截面板自身的左键点击，在选定游戏窗口位于前台时模拟 W/S。目标按进程的**完整可执行路径**匹配，不会只凭同名进程连接。选择文件时仅核对文件名和文件存在，不能鉴别真伪，请选择自己的可信安装。

短点击约保持 100 毫秒；焦点丢失或移出按钮优先取消。连续按住达到 30 秒后自动释放，松开重按可继续。按键释放是 Windows 全局输入事件，可能与同时长按的实体 W/S 或其他映射工具冲突。快速切换焦点存在系统时序限制，不能承诺所有情况下完全隔离输入。

程序还运行一个释放保护进程，正常随助手退出，异常结束时尽力释放助手已按住的 W/S；不能保证覆盖所有系统故障。退出后如果感觉按键仍在按住，可尝试手动按下再松开相应按键。

程序本身没有联网、遥测或自动更新逻辑。“启动游戏”通过 Steam URI 调用用户已安装的客户端。没有改键、自动行走、全游戏适配、中文补丁或游戏资源。

## 兼容性

Windows 10 / 11 x64、.NET Framework 4.8 / 4.8.1。游戏与助手按普通方式、相同权限运行。独占全屏、权限不同、游戏更新及其他系统环境可能影响显示或输入。ARM64 尚未验证。

请先将整个 ZIP 解压到可写文件夹，再打开 EXE。直接在压缩软件里打开可能进入临时目录，导致设置丢失；这并不证明它是显示故障的原因。

本包是 **0.1.0-experimental.3 实验版**。当前机器已观察到真实游戏悬浮显示；用户确认前后退及松开/移出停止正常。本轮未实测长时间按住、按住时切换软件或异常退出恢复。展示图来自真实测试窗口，不是游戏画面；详细构建和验证记录放在源码包。程序没有数字签名，请核对来源和附带 SHA-256，不要关闭系统防护。
